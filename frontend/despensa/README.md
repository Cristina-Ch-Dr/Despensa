# La Despensa — frontend

Frontend Angular de una aplicación de listas de la compra compartidas para familias y compañeros de piso. Actualmente están implementados el inicio de sesión y el registro.

Consulta la [Guía de desarrollo](./GUIA_DESARROLLO.md) para conocer la estructura del proyecto, sus convenciones y cómo ampliarlo manteniendo una arquitectura ordenada.

## Desarrollo

```bash
npm start
```

Abre `http://localhost:4200`. En desarrollo, las peticiones `/api` se envían al backend local `http://localhost:8080` mediante `proxy.conf.json`.

## Compilación

```bash
npm run build
```
